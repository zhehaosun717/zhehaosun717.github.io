## 2025-02-28 - Avoid Layout Thrashing with getBoundingClientRect
**Learning:** Calling `getBoundingClientRect()` inside high-frequency animation loops (like `requestAnimationFrame`) or event handlers (`mousemove`) causes severe layout thrashing. Furthermore, for elements actively transformed by animations (e.g., GSAP `x`/`y` transforms), reading `getBoundingClientRect()` continuously yields inaccurate, displaced coordinates.
**Action:** Cache bounding rectangles during low-frequency events (`resize`, `mouseenter`) by adding `window.scrollY`/`window.scrollX` to get absolute document coordinates. During high-frequency loops or `mousemove` events, dynamically calculate the current position using scroll differences (`window.scrollY - initialScrollY`) instead of querying the DOM.
