## 2024-06-18 - Avoid layout thrashing in high-frequency events via cached bounding boxes
**Learning:** Calling `getBoundingClientRect()` inside a `mousemove` event handler triggers synchronous style recalculations and layout thrashing. Furthermore, if the element is actively transformed (e.g., via GSAP animations), the bounding box recalculations yield inaccurate coordinates, causing visual stuttering and displaced coordinate offsets.
**Action:** Cache the element's bounding box and initial scroll position (`window.scrollY` and `window.scrollX`) on low-frequency events like `mouseenter`. In the high-frequency `mousemove` handler, dynamically calculate the adjusted bounding box offsets by subtracting the current scroll difference (`window.scrollY - initialScrollY`), entirely avoiding `getBoundingClientRect()`.
